## Project instructions

If `AGENTS.project.md` exists, it holds the user's project instructions. Follow
it with the same priority as this file.

## Spec status (required)

**`docs/spec_index.md` is the only place spec status lives.**

- Read that file first when you need to know what is done, in progress, or blocked.
- Do **not** scan every file under `docs/` to reconstruct status. That wastes context.
- Open a spec only when you are implementing or changing that spec.
- If you add a spec, change its status, block it, or complete it: update `docs/spec_index.md` **in the same change**. Statuses are exactly: `not started` | `in progress` | `completed` | `blocked`. Blocked rows must name the blocker in Notes.
